
API:	Interfaz que permite que dos aplicaciones se comuniquen e intercambien información.

REST:	Estilo de arquitectura para crear servicios web que utilizan solicitudes HTTP, como GET, POST, PUT y DELETE.

SOAP:	Protocolo de comunicación entre aplicaciones que utiliza mensajes estructurados, generalmente en XML.

JSON:	Formato ligero para almacenar e intercambiar información organizada en pares clave-valor.

XML:	Lenguaje de marcado que permite organizar y transportar información mediante etiquetas.

GraphQL:	Lenguaje de consulta para APIs que permite solicitar exactamente los datos que necesita el cliente.

¿Cómo se relacionan?

Todos estos conceptos participan en el intercambio de información entre aplicaciones. Por ejemplo, una aplicación de transporte puede solicitar a una API los horarios de los autobuses. La información puede viajar utilizando REST y estar representada en JSON o XML. También podría utilizar GraphQL para consultar los datos que necesita.
